# wurst-Xmenu

一个 Minecraft 26.3 Fabric 客户端小 mod：屏蔽 Wurst 客户端对游戏界面的干扰，恢复原版体验。

## 功能说明

- 隐藏暂停菜单的「Wurst Options」按钮，并还原原版按钮布局
- 恢复被 Wurst 隐藏的原版图标行（含 ModMenu 按钮）
- 屏蔽游戏内左上角的 Wurst logo 与版本号
- 屏蔽「聊天消息可以被举报」的系统通知

## 使用

把 `wurst-Xmenu-26.3.jar` 放进 `.minecraft/mods` 即可。需要 Fabric Loader ≥ 0.19.5，无需 Fabric API；未安装 Wurst 时本 mod 自动不生效，不影响游戏。
